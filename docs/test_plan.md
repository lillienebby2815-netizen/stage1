# 测试计划

每项功能单独完成、单独验证、单独记录；验证通过后再申请对应GitHub提交。

| 编号 | 功能 | 验证方法 | 通过标准 | 结果 |
|---|---|---|---|---|
| C-01 | 蜂鸣器提示 | 上电或烧录后观察声音 | 出现预期提示音 | 待测 |
| C-02 | LED流水灯 | 运行程序并观察LED | LED按预期循环，能反映程序运行 | 待测 |
