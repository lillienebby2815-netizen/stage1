# 任务要求

## 赛事来源

- 赛事通知：SuperPower × MPS杯暨27赛季机甲大师校内赛嵌入式组通知。
- 规则手册：SuperPower × MPS杯暨27赛季机甲大师校内赛规则手册 V1.0.0。

## 第一阶段嵌入式任务

### C板基本功能

该项是晋级必要条件，必须完成：

- 上电或成功烧录后蜂鸣器提示；
- C板LED流水灯，用于观察程序是否堵塞；
- 上位机串口打印IMU三轴数据；
- C板与DT7遥控器正常通信。

### 姿态与电机联动

需要使用C板IMU和两台GM6020完成联动：

- DT7右拨杆下档时，全部电机失能；
- DT7右拨杆中档时进入姿态联动模式；
- A电机与C板Yaw保持1:1联动；
- B电机按照左拨杆选择的比例联动；
- 手动转动任一电机时，另一台按对应比例跟随；
- 手动转动后更新联动参考零点；
- C板实际Yaw应保持不变。

左拨杆比例表必须以导师或赛事组织方的正式说明为准，不能自行猜测。

### 24V转5V降压板

基于MPS MP4420A完成：

- 嘉立创EDA原理图；
- 嘉立创EDA PCB；
- XT30公头输入、XT30母头输出；
- PCB上的MPS商标；
- BOM和制板文件；
- ERC、DRC和导师审图记录。

### 版本管理和成果

- 代码使用Git管理；
- 提交历史应体现开发过程；
- 仓库包含README；
- 每完成一个可独立验证的功能，单独测试并上传一次GitHub；
- 最终整理代码、README、测试记录、原理图、PCB、Gerber、BOM和演示视频。

## 安全要求

- 首次通电前检查极性、绝缘、接口、短路风险和机构干涉；
- 新代码首次测试时电机离地或可靠固定，输出限幅设低；
- 首次控制电机前确认DT7右拨杆下档可以可靠失能；
- 烧录、接线、拆装和人工转动机构前断电；
- 出现失控、异味、过热、冒烟或线束拉扯时立即失能并断电。
